# internship-portfolio-web-task-6

## Project Overview
This project is a **personal portfolio website** built using **Flask**. The website showcases personal information, skills, projects, and includes a contact form for visitors to reach out. The goal was to create a simple, real-world web application that demonstrates basic web development skills using Python, Flask, HTML, and CSS.

---

## Tools & Technologies
- **Python** – Main programming language for backend logic.  
- **Flask** – Python web framework used to handle routing and templates.  
- **HTML / CSS** – Used to structure and style the web pages.  
- **CSV** – Used to store contact form submissions locally.

---

## Key Features
1. **Flask Routing** – Handles multiple pages (Home, Projects, Contact).  
2. **Homepage** – Displays personal information, skills, and highlights portfolio projects.  
3. **Projects Page** – Lists different projects with descriptions and links to repositories or live demos.  
4. **Contact Form** – Allows visitors to send messages, which are stored in a CSV file.  
5. **Reusable Templates** – Base template for consistent header, footer, and navigation across pages.  
6. **Static Files** – CSS and images used to style and enhance the website’s appearance.  

---

## How It Works
1. Users visit the homepage to see personal info and project highlights.  
2. Navigation links allow users to explore Projects and Contact pages.  
3. Visitors can fill out the contact form to send messages.  
4. Submitted messages are saved locally in a CSV file and a success page is displayed.  
5. The website is fully styled using CSS for a clean and professional look.

---

## Outcome
- A **fully functional portfolio website** built with Flask.  
- Demonstrates **basic web development skills** (routing, templates, forms, styling).  
- Ready to be **extended with more projects, email functionality, or deployment**.
